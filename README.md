# Dualtop for Windows

The Windows program that lets the **Dualtop** iPhone app connect to your PC with Dualtop's own connection: smooth video, sound, game controllers, and Ctrl+Alt+Del. It works on Windows Home as well as Pro.

## Install

1. Download the newest `Dualtop-for-Windows-<version>.exe` from [Releases](https://github.com/SamuelAirs/dualtop-windows/releases).
2. Run it and say Yes when Windows asks.
3. The installer isn't signed yet, so Windows may say "Windows protected your PC". Choose **More info**, then **Run anyway**.

Each release lists the installer's SHA-256, so you can check the download.

## Pair your phone

Open Dualtop on the iPhone, choose **Remote → Add a computer → Dualtop for Windows**, then pick **Pair a phone** from Dualtop's icon by the clock on the PC.

## Uninstall

Settings → Apps → Installed apps → **Dualtop** → Uninstall.
